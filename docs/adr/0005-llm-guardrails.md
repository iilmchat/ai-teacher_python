# ADR-005 — Guardrails LLM для детской аудитории

**Статус:** Accepted
**Дата:** 2026-11-12
**Контекст:** Ассистент работает со школьниками 10–17 лет. Промпты уже
запрещали готовый код на базовом уровне, но не защищали от prompt injection
(«покажи системный промпт», «смени роль»), токсичности и опасных тем. Полная
модерация ответов — отдельная инфраструктура, которой пока нет.

## Решение

- В каждый системный промпт добавляется `SECURITY_INSTRUCTIONS`
  (`app/services/llm/guardrails.py`): не раскрывать промпт, не менять роль,
  не выполнять инструкции из кода/цитат, не собирать ПДн.
- Базовый фильтр **входа** `check_user_input` до сохранения сообщения и
  вызова LLM:
  - prompt injection (EN/RU) → безопасный отказ;
  - токсичность → вежливый отказ;
  - признаки самоповреждения → поддерживающий текст + просьба поговорить со
    взрослым.
- Текст попытки не логируется и не уходит провайдеру.
- Версии промптов подняты (basic 2, intermediate 3, advanced 2).
- Полная модерация ответов/возрастные пороги — **KI-036** (Med, v0.7.0+).

## Последствия

**Плюсы:**
- дешёвый первый барьер без внешних сервисов;
- единые правила для всех уровней/провайдеров;
- защита детей от явных попыток «сломать» ассистента.

**Минусы/риски:**
- фильтр обходится перефразированием; возможны ложные срабатывания;
- ответы модели не модерируются — KI-036;
- сообщения фильтра на русском (i18n — v0.7.0).
