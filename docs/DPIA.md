# DPIA.md — оценка воздействия на приватность (S38-001)

> Проект: AI Teacher for Python. Аудитория — школьники 10–17 лет. Документ
> описывает обработку ПДн, риски и меры; не заменяет юридическую оценку
> владельца. Связанные документы: `PRIVACY.md`, `SECURITY_AUDIT.md`,
> `ASVS_L1.md`.

**Дата:** 2026-11-12 · **Версия продукта:** v0.6.0 (пилот)

## 1. Цели и правовое основание

| Цель | Данные | Основание |
|------|--------|-----------|
| Обучение и проверка задач | email/username, прогресс, код, попытки | исполнение договора/образовательная услуга |
| Чат с ассистентом | тексты сообщений, контекст задачи | исполнение договора |
| Безопасность и аудит | IP входа, действия teacher/admin, сессии | законный интерес (защита сервиса) |
| Уведомления | email (опционально), настройки | согласие/настройки пользователя |
| Качество LLM | оценки ответов, агрегированные метрики | законный интерес (улучшение без обучения на чатах) |

Специальные категории ПДн не запрашиваются. Возраст/адрес/телефон не собираются;
для детей младше 14 согласие родителей — организационная ответственность
оператора (школы/владельца пилота), технически сервис не проверяет возраст.

## 2. Потоки данных

```
Ученик → frontend → backend → PostgreSQL/Redis
                         └→ LLM (DeepSeek) — только текст диалога
                         └→ Sentry — только техническая ошибка без PII
                         └→ S3 — зашифрованный бэкап (age), если включён
```

- **LLM:** системный промпт, последние ≤20 сообщений, текст задачи; без email,
  username, user_id, IP (см. `PRIVACY.md` §8).
- **Sentry:** тип/сообщение ошибки, stacktrace без строк кода, релиз/окружение;
  email/IP маскируются, тело запроса не отправляется.
- **Бэкапы:** дамп БД, gzip + `age`; локально и/или Selectel S3; доступ у
  владельца.

## 3. Сроки хранения

| Данные | Срок |
|--------|------|
| Аккаунт, прогресс | пока аккаунт активен |

| Резервные копии | 14 дней локально; S3 — lifecycle владельца |

## 4. Риски и меры

| Риск | Вероятность | Влияние | Меры |
|------|-------------|---------|------|
| Утечка ПДн через API/логи | средняя | высокое | RBAC, ownership-checks, маскирование email, Sentry-фильтр, gitleaks |
| Перехват токенов (XSS) | средняя | высокое | CSP, короткий access-token, refresh-ротация/отзыв; `KI-027` (localStorage) принят до v0.7.0 |
| Деактивированный пользователь сохраняет доступ | была высокая | высокое | закрыто S34-001 (`get_current_active_user`) |
| Prompt injection/неуместный контент для детей | средняя | высокое | защитные инструкции + фильтр S38-004; полная модерация — `KI-036` |
| Передача лишнего LLM-провайдеру | средняя | среднее | минимум контекста, без идентификаторов; локальный LM Studio как альтернатива |
| Потеря данных | средняя | высокое | ежедневный бэкап, age, restore drill, `BackupStale` |
| Доступ к бэкапам | низкая | высокое | шифрование, приватный ключ вне репозитория, S3-ключи в secrets |
| Трансграничная передача (DeepSeek) | средняя | среднее | раскрытие в PRIVACY, локальный провайдер, договорные условия |

## 5. Права субъектов

Доступ/исправление/удаление/экспорт/смена пароля/отзыв сессий — см.
`PRIVACY.md` §6. E-mail-подтверждение и самостоятельный сброс пароля пока
отсутствуют (`KI-035`, v0.7.0); удаление аккаунта доступно.

## 6. Остаточные риски

- JWT в `localStorage` и неотзываемый access-токен (`KI-027`, Accepted Low).
- Нет полноценной модерации ответов LLM для детей (`KI-036`, Med).
- Нет e-mail-восстановления (`KI-035`, Med).
- Пилот на одном узле: компрометация VPS = компрометация данных; нужен
  отдельный VPS для публичного прода и юридическая проверка 152-ФЗ.
- Merge-gate CI не активирован (`KI-023`, In Progress) — процессный риск.

## 7. Вывод

Для **закрытого пилота** обработка допустима при выполнении мер из
`SECURITY_AUDIT.md` и `RUNBOOK.md`. Для публичного запуска требуются:
юридическая оценка/согласия, отдельный VPS, закрытие `KI-027`/`KI-035`/
`KI-036`, активация merge-gate и (желательно) внешний пентест.
