# MANUAL_TESTING_GUIDE — ручные кейсы и чек-лист приёмки

Проверки, которые нельзя (или пока невыгодно) автоматизировать. Автотесты —
backend **341 passed + 1 skipped** + frontend 80 unit / 12 e2e; здесь — то,
что смотрит человек.

---

## 0. Подготовка

```bash
docker compose up -d postgres redis
cd backend && venv\Scripts\alembic.exe upgrade head && venv\Scripts\python.exe scripts\seed_tasks.py
venv\Scripts\uvicorn.exe app.main:app --port 8000
cd frontend && pnpm dev        # http://127.0.0.1:3000
```

Отметьте в чек-листе: `[ ]` — не проверено, `[x]` — ок, `[!]` — дефект (заведите KI).
