# USER_GUIDE — как пользоваться ассистентом

Руководство для ученика (10–17 лет), учителя и родителя.

---

## 1. Регистрация и вход

1. Откройте главную страницу и нажмите «Регистрация».
2. Укажите email, имя пользователя (от 3 символов) и пароль (от 8 символов).
3. После регистрации вы сразу попадаете в систему как **ученик**.

Вход — по имени пользователя **или** по email: оба варианта работают.

---

## 2. Три уровня помощи

Уровень определяет, насколько подробно ассистент помогает. Переключить можно
в **Профиле** (применяется к новым чатам) или выбрать при создании чата.

| Уровень | Что делает ассистент | Готовый код |
|---------|----------------------|-------------|
| **Базовый** | задаёт наводящие вопросы, подсказывает, где ошибка | ❌ не даёт |
| **Средний** | объясняет причину ошибки, показывает правильный синтаксис на примере | ❌ только фрагмент |
| **Продвинутый** | даёт полное решение с разбором, альтернативами и стилем | ✅ даёт |

Подробнее — [ASSISTANT_LEVELS.md](ASSISTANT_LEVELS.md).

> Совет: начните с базового. Если совсем не получается — переключитесь на
> средний, а продвинутый используйте, чтобы **сверить** своё решение.

---

## 3. Чат с ассистентом

1. Раздел **«Чат»** → «Новый чат» (выберите уровень).
2. Напишите вопрос или вставьте код.
   - `Enter` — отправить, `Shift+Enter` — новая строка (удобно для кода).
3. Ответ появляется постепенно (стриминг). Если стриминг недоступен,
   ответ придёт целиком — на результат это не влияет.
4. Слева — список ваших чатов; можно создать несколько с разными уровнями
   и удалить ненужные.

**Как спрашивать, чтобы помочь себе:**

- Вместо «сделай за меня» → «почему у меня цикл не заканчивается?»
- Приложите код и текст ошибки — ассистент точнее укажет место.
- Спросите «что будет, если…» — так быстрее понять правило.

---

## 4. Песочница кода

Раздел **«Песочница»** — безопасная среда выполнения Python.

1. Напишите код (или вставьте пример).
2. «Запустить» — код выполнится, ниже появится вывод, ошибка и замечания линтера.
3. `input()` работает: в одном запуске можно ввести данные, но интерактивно
   вводить в консоль нельзя — используйте тесты задач, чтобы проверить разные
   входные данные.

Что доступно: `math`, `random`, `datetime`, `collections`, `itertools`,
`functools`, `string`, `re`, `statistics`, `decimal`, `fractions`, `json`.

Что запрещено: `os`, `sys`, `subprocess`, `open`, `eval`, `exec`, сеть, файлы.
Лимит времени — несколько секунд.

---

## 5. Задачи

1. Раздел **«Задачи»**: фильтр по сложности, прогресс сверху.
2. Откройте задачу: описание, попытки, подсказки.
3. **Подсказки открываются по одной** — нажмите «Показать подсказку».
   Сначала попробуйте без них.
4. Напишите решение в редакторе и нажмите «Проверить решение».
5. Результат: сколько тестов пройдено и на каком вводе расходится вывод
   (показаны ожидаемое и фактическое значения).

Задача считается решённой, когда пройдены **все** тесты. Попытки считаются,
но не ограничены.

---

## 6. Прогресс

На странице задач — полоса прогресса и разбивка по сложности: сколько решено
из скольких. Отдельной страницы статистики пока нет.

---

## 7. Профиль

- видно имя, email, роль;
- смена уровня помощи (влияет на новые чаты);
- текущий уровень помечен на странице чата.

---

## 8. Роли

| Роль | Что может |
|------|-----------|
| `student` | чат, песочница, задачи, свой прогресс |
| `teacher` | всё, что ученик, + создание/изменение/удаление задач |
| `admin` | всё, что учитель, + раздел «Администрирование»: пользователи, роли, аналитика |

Роль выдаёт только администратор — при регистрации всегда создаётся ученик.

### 8.1. Импорт и генерация задач (для преподавателя)

**Импорт из файла.** Формат — JSON или YAML: массив задач или `{tasks: [...]}`.
Обязательные поля: `title`, `description`, `test_cases`; опционально —
`difficulty`, `category`, `tags`, `hints`, `solution_template`.

```bash
cd backend
python scripts/import_tasks.py tasks.yaml
```

Отчёт: `{created, skipped, errors}`. Дубликаты по заголовку пропускаются,
битая запись не мешает импорту остальных. Через API:
`POST /api/v1/tasks/import` (teacher/admin), выгрузка —
`GET /api/v1/tasks/export?format=json|yaml`.

**Генерация через LLM.** `POST /api/v1/tasks/generate` с
`{topic, difficulty, count ≤ 5}`: модель возвращает задачи с тест-кейсами,
каждая проверяется прогоном эталонного решения в песочнице. Невалидные
попадают в `rejected` и не сохраняются.

**Теги и поиск.** В каталоге: `GET /api/v1/tasks?tag=loops&q=сумма`,
категории — `GET /api/v1/tasks/categories`.

**История версий.** Перед каждой правкой сохраняется снимок задачи;
`GET /api/v1/tasks/{id}/versions` и
`POST /api/v1/tasks/{id}/versions/{v}/restore` (teacher/admin).
UI для всего этого — в спринте 15.

## 9. Частые вопросы

**Ассистент не отвечает, ошибка 503.**
Не настроен провайдер LLM: нужен `DEEPSEEK_API_KEY` в конфигурации или
запущенный LM Studio.

**Код не запускается: «Импорт запрещённого модуля».**
В песочнице нельзя импортировать системные модули. Используйте разрешённые
(список в разделе 4).

**Пишет «Превышен лимит времени».**
Скорее всего бесконечный цикл — проверьте условие выхода.

**Задача не засчитана, хотя вывод верный.**
Сравниваются все тесты; посмотрите, на каком вводе расходится вывод.
Частая причина — лишние символы или другой регистр букв.

**Забыл пароль.**
Восстановление пока не реализовано — обратитесь к администратору.
