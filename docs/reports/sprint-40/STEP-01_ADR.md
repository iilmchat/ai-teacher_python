# S40-001 — Architecture Decision Records

**Дата:** 2026-11-12
**Спринт:** 40
**Шаг:** S40-001
**Статус:** завершено

## 1. Задача

Зафиксировать ключевые архитектурные решения этапа v0.6.0 в формате ADR
(Контекст → Решение → Последствия), чтобы новые участники понимали «почему
так», а пересмотр решений шёл через новый ADR, а не правку истории.

## 2. Что сделано

Создан `docs/adr/`:

| ADR | Решение |
|-----|---------|
| [ADR-001](../../adr/0001-ghcr-digest-deploy.md) | GHCR и digest-пиннинг для деплоя |
| [ADR-002](../../adr/0002-caddy-edge.md) | Caddy как edge (TLS, WS, лимиты) |
| [ADR-003](../../adr/0003-trusted-proxies-refresh-body.md) | `TRUSTED_PROXIES`, refresh в теле, `is_active` в RBAC |
| [ADR-004](../../adr/0004-backups-systemd-age-s3.md) | Бэкапы: systemd + age + S3 |
| [ADR-005](../../adr/0005-llm-guardrails.md) | Guardrails LLM для детской аудитории |
| [ADR-006](../../adr/0006-secrets-file.md) | Секреты через `*_FILE`/Docker secrets |
| [ADR-007](../../adr/0007-cicd-gates.md) | CI-гейты, preflight, GitFlic merge-gate |

`docs/adr/README.md` — индекс, статусы, шаблон и правило «ADR не
переписывается задним числом».

## 3. Проверки

| Проверка | Команда | Результат |
|----------|---------|-----------|
| Файлы ADR на месте | `Get-ChildItem docs/adr` | 8 файлов (README + 7 ADR) |
| Формат разделов | ручная проверка | у каждого ADR: Контекст, Решение, Последствия (плюсы/минусы), ссылки |
| Ссылки из README/docs | ручная проверка | валидны |

## 4. Риски

- ADR-007 имеет статус **Accepted (активация — владелец)**: сам скрипт
  GitFlic-гейта готов, но required checks включаются вручную (`KI-023`).
- ADR фиксируют состояние на 2026-11-12; при изменении решений нужен новый
  ADR со ссылкой `Supersedes`.

## 5. Проблемы и открытия

Новых KI нет. `KI-023` остаётся `In Progress` — платформенное ограничение
GitHub Free/GitFlic, не дефект кода.

## 6. Дальнейшие шаги

- При появлении со-мейнтейнеров — добавить их в CODEOWNERS и назначить
  ревьюеров по ADR.
- Пересмотр ADR-005 (полная модерация ответов) — вместе с `KI-036` в v0.7.0.

## 7. Итог шага

и CONTRIBUTING (S40-002/003).
