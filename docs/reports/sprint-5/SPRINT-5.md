## 7. Обоснование

- **Уровень — свойство сессии, а не только профиля.** Ученик может вести
  диалог на базовом уровне и параллельно разбирать задачу на продвинутом,
  не переключая профиль.
- **Наследование уровня без дефолта в схеме.** Найден баг: `level="basic"`
  в `ChatSessionCreate` перебивал уровень профиля. Теперь `level=None`
  означает «взять из профиля».
- **Fallback на базовый уровень.** Если файл промпта отсутствует (например,
  новая экспериментальная ступень), чат продолжает работать вместо 500.
- **Описания уровней в коде, тексты промптов в файлах.** API отдаёт
  человекочитаемые названия и признак `gives_ready_code`, а инструкции для
  модели остаются версионируемыми файлами.
- **RBAC через существующий `require_role`.** Админские маршруты используют
  ту же проверку, что и остальной проект; администратор имеет доступ всегда.
