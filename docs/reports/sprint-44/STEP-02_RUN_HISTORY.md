## 1. Что сделано

1. **Карточка «История запусков».** `CodePage` запрашивает
   `GET /code/history?skip=&limit=` при открытии и после каждого запуска:
   новый результат виден сразу, без перезагрузки страницы.
2. **Список записей.** Каждая строка показывает время, статус («Успех» /
   «Ошибка») и длительность. Запись раскрывается: код, вывод и ошибка (если
   была).
3. **«Запустить снова».** Код записи возвращается в редактор и сохраняется как
   черновик; прошлый результат очищается. Автоматического запуска нет — это
   отдельное действие ученика.
4. **Пагинация.** Запрашивается на одну запись больше размера страницы
   (10 + 1), поэтому «Показать ещё» появляется только когда следующая
   страница действительно есть. Повторные записи отсекаются по `id`.
5. **Пустое состояние и ошибка сети.** Пока запусков нет — подсказка
   «запустите код»; при сбое загрузки — сообщение и кнопка «Повторить».
   Ошибка истории не блокирует редактор, запуск и разбор.
6. **Типы и i18n.** В `types/api.ts` добавлен `ExecutionRecord`; новые строки
   заведены в `ru.json` и `en.json`.

## 4. Проблемы и отклонения

- **Backend не менялся.** `GET /code/history` уже возвращает всё нужное
  (код, вывод, ошибку, статус, длительность, время); шаг закрывает `KI-030`
  в части этого маршрута только на фронтенде.
- **stdin в истории не хранится.** Модель `code_executions` не содержит
  колонки `stdin`; запись раскрывает код, вывод и ошибку. Хранение stdin
  потребовало бы миграции БД и не входило в оценку шага (4 ч).
- **E2E в этом шаге не добавлялся.** Сквозной сценарий «код → stdin → вывод →
  история» станет частью DoD спринта после S44-003/S44-004.
- **Полный backend-прогон локально недоступен** (Docker Desktop и Postgres
  `:5434` остановлены); затронутый `test_code_api.py` прошёл, полный прогон
  выполнит CI.

## 5. Обоснование решений

| Вариант | Выбран | Почему |
|---------|--------|--------|
| Показывать историю сразу или по кнопке | **Сразу при открытии** | Это контекст, а не действие: ученику полезно видеть прошлые запуски без лишнего клика. |
| «Запустить снова» запускает код или только восстанавливает | **Только восстанавливает** | Запуск — явное действие; иначе клик по истории неожиданно тратит лимит и создаёт новую запись. |
| Определять «есть ещё» по размеру страницы или запросом +1 | **Запрос +1** | Не показывает «Показать ещё» на последней странице, если записей ровно кратно 10. |
| Ошибка истории блокирует страницу или только карточку | **Только карточку** | История вторична: сбой сети не должен мешать писать и запускать код. |
