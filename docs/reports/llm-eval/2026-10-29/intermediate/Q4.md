# Что такое список в Python

**Список (list)** — это упорядоченная коллекция элементов, которую можно менять: добавлять, удалять, заменять элементы. Записывается в квадратных скобках `[...]`, элементы разделяются запятыми.

## Пример

```python
fruits = ["яблоко", "банан", "груша"]
print(fruits[0])      # яблоко — индексы с нуля
fruits.append("киви") # добавили в конец
print(len(fruits))    # 4 — длина списка
```

## Ключевые свойства

1. **Индексация с нуля**: первый элемент — `[0]`, последний — `[-1]`.
2. **Изменяемость**: `fruits[1] = "слива"` — заменяет элемент, в отличие от строки или кортежа.
3. **Разные типы внутри**: `[1, "текст", 3.5, True]` — допустимо, хотя на практике чаще однотипные.

## Сравнение: как было / как правильно

```python
# ❌ Частая ошибка новичка
fruits = "яблоко, банан, груша"   # это строка, а не список
fruits[0]                          # 'я' — не то, что ждали

# ✅ Правильно
fruits = ["яблоко", "банан", "груша"]
fruits[0]                          # 'яблоко'
```

## Основные операции

| Действие | Код |
|---|---|
| Добавить в конец | `lst.append(x)` |
| Вставить по индексу | `lst.insert(1, x)` |
| Удалить по значению | `lst.remove(x)` |
| Удалить по индексу | `del lst[0]` или `lst.pop(0)` |
| Срез | `lst[1:3]` |
| Проверить наличие | `x in lst` |
