# Разбор твоего решения

## Причина ошибки

Сам по себе код **не содержит ошибки** — `print(sum(range(10)))` синтаксически корректен и выведет `45`. Но если задача была, например, «сумма чисел от 1 до 10» или «сумма чётных чисел», то ошибка **логическая**: `range(10)` даёт числа `0..9`, а не `1..10`.

## Правильный приём

```python
print(sum(range(1, 11)))      # 1 + 2 + ... + 10 = 55
print(sum(range(0, 10, 2)))   # только чётные: 0+2+4+6+8 = 20
```

## Сравнение «как было» / «как правильно»

**Было:**
```python
sum(range(10))   # 0+1+2+...+9 = 45  (10 чисел, начиная с 0)
```

**Правильно (если нужна сумма 1..10):**
```python
sum(range(1, 11))  # 1+2+...+10 = 55  (10 чисел, начиная с 1)
```

## Почему это работает

1. `range(start, stop)` включает `start`, но **не включает** `stop` — правая граница «открыта».
2. Чтобы получить N чисел от 1 до N, нужно `range(1, N+1)` — не забывай про `+1`.
3. Третий аргумент `range(start, stop, step)` задаёт шаг — удобно для чётных/нечётных.
