# Разбор задачи «Сумма чисел до N»

Ты не прислал свой код, поэтому давай разберём **самый частый случай ошибки** в этой задаче — когда сумма получается неверной из-за границ `range()`.

## Причина ошибки (типичная)

Часто пишут `for i in range(N):` и получают сумму **до N−1**, потому что `range(N)` не включает само число `N`. Либо переменную суммы объявляют **внутри цикла** — тогда она обнуляется на каждом шаге.

## Пример правильного приёма

```python
total = 0                 # сумма ДО цикла
for i in range(1, N + 1): # от 1 до N включительно
    total += i
print(total)
```

## Короткое объяснение

1. **`range(a, b)`** идёт от `a` до `b−1`. Чтобы включить `N`, пишем `range(1, N + 1)`.
2. **Накопитель (`total`) объявляется один раз до цикла** — иначе он будет сбрасываться на каждой итерации.
3. **`total += i`** — это сокращение для `total = total + i`. Работает только если `total` уже существует.

## Сравни «как было» и «как правильно»

```python
# ❌ Неверно: сумма 0+1+...+(N-1), N не входит
total = 0
for i in range(N):
    total += i
```

```python
# ✅ Верно: сумма 1+2+...+N
total = 0
for i in range(1, N + 1):
    total += i
```
