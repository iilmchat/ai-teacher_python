# Разбор: сумма чисел до N

## Причина, по которой нельзя просто «написать»
Здесь нет ошибки в коде — есть учебная задача. Цель — чтобы ты понял **цикл и накопление суммы**, а не получил готовый ответ. Покажу приём.

## Правильный приём: накопитель (аккумулятор)

Идея: заводим переменную-«копилку» **до** цикла, а внутри цикла прибавляем к ней.

```python
total = 0                # копилка пустая
for i in range(1, 6):    # числа 1, 2, 3, 4, 5
    total = total + i    # кладём в копилку
print(total)             # 15
```

## Что важно запомнить

1. **Копилку создаём ДО цикла.** Если объявить `total = 0` внутри цикла — она будет обнуляться каждую итерацию, и в конце останется только последнее число.
2. **`range(1, N+1)`**, а не `range(N)` — иначе последнее число N не попадёт в сумму (верхняя граница не включается).
3. **`total += i`** — то же самое, что `total = total + i`, просто короче.

## Сравнение «как было / как правильно»

```python
# ❌ Так — копилка обнуляется на каждом шаге
for i in range(1, 6):
    total = 0
    total = total + i
print(total)   # 5 — потеряли всё, кроме последнего

# ✅ Так — копилка живёт весь цикл
total = 0
for i in range(1, 6):
    total = total + i
print(total)   # 15
```

## Твои шаги для задачи

1. Спроси у пользователя `N` через `int(input(...))`.
2. Заведи `total = 0` **до** цикла.
3. Прокрути цикл `for i in range(1, N + 1):` и прибавляй `i` к `total`.
4. Выведи `total`.
