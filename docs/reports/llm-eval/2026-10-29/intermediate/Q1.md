# intermediate · Q1

**Вопрос:** Почему `if x = 5:` не работает?

**Провайдер:** deepseek (deepseek-chat) · **Версия промпта:** 1

**Предупреждения политики:** нет

## Ответ

**Причина ошибки:** в Python `=` — это оператор *присваивания* (положить значение в переменную), а не сравнения. Внутри `if` нужно *сравнение*, и для него используется `==`. Поэтому `if x = 5:` — синтаксическая ошибка (`SyntaxError`).

**Правильный приём:**

```python
x = 5          # присваивание: кладём 5 в x
if x == 5:     # сравнение: спрашиваем "x равно 5?"
    print("да")
```

**Как было / как правильно:**

```python
# ❌ так нельзя
if x = 5:
    ...

# ✅ так правильно
if x == 5:
    ...
```

**Короткое объяснение:**
1. `=` — «положи значение» (assignment). `==` — «равно ли?» (comparison, даёт `True`/`False`).
2. `if` ждёт после себя *выражение*, которое можно вычислить в `True`/`False`. Присваивание выражением в Python не является — отсюда `SyntaxError`.
3. Есть ещё `!=` (не равно), `<`, `>`, `<=`, `>=` — тоже сравнения, их можно ставить в `if`.

**Мини-упражнение:** напиши три строки: присвой переменной `age` число, затем проверь через `if` два условия — «больше 12» и «ровно 12» — и выведи разные сообщения. Подумай, где нужен `=`, а где `==`.
