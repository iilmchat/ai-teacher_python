# intermediate · Q3

**Вопрос:** Код: `while i < 10: print(i)` — зависает

**Провайдер:** deepseek (deepseek-chat) · **Версия промпта:** 1

**Предупреждения политики:** нет

## Ответ

**Причина ошибки:** в цикле `while` переменная `i` не изменяется, поэтому условие `i < 10` остаётся истинным всегда — цикл бесконечный. Обычно забывают строку `i += 1` внутри тела цикла.

**Пример правильного приёма:**

```python
i = 0
while i < 10:
    print(i)
    i += 1   # ← обязательно меняем условие выхода
```

**Как было / как правильно:**

```python
# ❌ было: i не меняется — условие всегда True
while i < 10:
    print(i)

# ✅ правильно: i растёт, условие когда-то станет False
while i < 10:
    print(i)
    i += 1
```

**Короткое объяснение:**
1. `while` проверяет условие *перед каждой* итерацией. Если внутри ничего не меняется — условие не изменится.
2. Любой цикл `while` должен иметь «шаг к выходу»: изменение счётчика, ввод пользователя, `break`.
3. `i += 1` — это то же, что `i = i + 1`; без него `i` навсегда остаётся `0`.

**Мини-упражнение:** напиши цикл, который выводит чётные числа от 0 до 20 через `while`. Подумай: какой шаг (`+= 1` или `+= 2`) логичнее и почему? Покажи свой вариант — проверим вместе.
