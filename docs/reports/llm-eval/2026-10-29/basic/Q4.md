# basic · Q4

**Вопрос:** Что такое список?

**Провайдер:** deepseek (deepseek-chat) · **Версия промпта:** 1

**Предупреждения политики:** нет

## Ответ

Отличный вопрос! Представь шкафчик с ячейками, у каждой ячейки есть номер — как в раздевалке. Список в Python — это такая «коробка», где хранится несколько значений по порядку. Например, список дней недели или любимых чисел.

```python
# это просто иллюстрация синтаксиса, не твоя задача
fruits = ["яблоко", "банан", "груша"]
```

Ячейки нумеруются с нуля: первая — номер 0, вторая — 1. К ним обращаются по номеру, как «подъезд 0, квартира 2».

А как ты думаешь: если в списке три фрукта, какой номер будет у последнего — 2 или 3?
