# basic · Q1

**Вопрос:** Почему `if x = 5:` не работает?

**Провайдер:** deepseek (deepseek-chat) · **Версия промпта:** 1

**Предупреждения политики:** нет

## Ответ

Отличный вопрос — на нём спотыкаются почти все новички! 🙂

Смотри: в Python знак `=` — это не «равно», а «положи в коробку». Как будто ты пишешь на коробке подпись «x» и кладёшь туда число 5. А `if` хочет не действие, а **вопрос**: «правда ли, что...?». Действие и вопрос — разные вещи, поэтому Python путается.

Для сравнения (вопроса) есть отдельный знак — два символа подряд. Вот пример на других данных, просто чтобы ты увидел синтаксис:

```python
age = 12          # кладу в коробку age число 12
if age == 12:     # спрашиваю: «в коробке age лежит 12?»
    print("да")
```

Заметил, чем отличаются строки `age = 12` и `age == 12`? Как думаешь, что произойдёт, если в `if` поставить один знак `=`?
