## 1. Цель и результат

Учитель видит, что ученик реально написал, разбирает конкретное назначение,
управляет сроками и массово работает со списком класса. Все шесть задач
выполнены:

| Задача | Результат |
|--------|-----------|
| S46-001 | Работы ученика: список попыток, деталь с кодом и разбором, `best_solution` в прогрессе; доступ — владелец класса |
| S46-002 | Комментарий учителя к попытке (`attempt_feedback`), уведомление ученику, показ в истории и карточке работы |
| S46-003 | Drill-down по назначению: «кто как справился», распределение попыток, проблемные и просрочившие |
| S46-004 | Перенос срока (`PATCH`) и снятие (`DELETE`) назначения; идемпотентность, прогресс сохраняется |
| S46-005 | Массовое добавление учеников списком логинов и массовое снятие с отчётом |
| S46-006 | Объявления класса, лента в «Моих заданиях», уведомление всем ученикам |

## 2. Что появилось в API

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/teacher/students/{id}/attempts` | работы ученика по задачам (`task_id?`, пагинация) |
| GET | `/teacher/students/{id}/attempts/{attempt_id}` | деталь: код, разбор, комментарии |
| POST | `/teacher/attempts/{id}/feedback` | комментарий 1…2000 символов, upsert |
| GET | `/classrooms/{id}/assignments/{assignment_id}/analytics` | drill-down, `problem_threshold` |
| PATCH | `/classrooms/{id}/assignments/{assignment_id}` | перенос срока |
| DELETE | `/classrooms/{id}/assignments/{assignment_id}` | снятие, идемпотентно |
| POST | `/classrooms/{id}/members/bulk` | до 100 логинов → `added/skipped/unknown` |
| DELETE | `/classrooms/{id}/members/bulk` | массовое снятие → `removed/skipped` |
| GET/POST | `/classrooms/{id}/announcements` | список и публикация объявлений |
| DELETE | `/classrooms/{id}/announcements/{id}` | удаление автором или владельцем |
| GET | `/me/announcements` | лента объявлений всех классов ученика |

Миграции: `020` (`attempt_feedback`), `021` (`classroom_announcements`).
Новые типы уведомлений: `attempt_feedback`, `announcement`.
Аудит: `attempt.feedback_added`, `assignment.updated`, `assignment.deleted`,
`classroom.members_bulk_added`, `classroom.members_bulk_removed`,
`announcement.created`, `announcement.deleted`.

## 5. Проблемы и отклонения

- **Комментарий один на пару «попытка — учитель».** Обсуждение в ветке не
  поддерживается: для разбора достаточно одного актуального текста, история
  изменений остаётся в аудите.
- **`updated_at` у комментария нет.** Дата создания не меняется при
  редактировании — сортировка комментариев стабильна.
- **Повторная отправка комментария уведомляет снова.** Учитель уточнил
  замечание — ученик должен об этом узнать.
- **Массовый перенос срока — цикл `PATCH`.** Отдельный bulk-эндпоинт не
  нужен: назначений в классе десятки. При ошибке на одном шаге уже
  перенесённые остаются перенесёнными.
- **Массовое снятие использует `DELETE` с телом.** `fetch` и FastAPI это
  поддерживают; семантика удаления важнее стилистики.
- **`GET /me/announcements` сверх буквы задачи.** Без него лента на «Моих
  заданиях» требовала бы запрос на каждый класс ученика.
- **Публикует объявления только владелец.** Роли со-учителя пока нет; поле
  `author_id` и удаление «автор или владелец» готовы к её появлению.
- **E2E-фикстуры.** Для сценария с учителем добавлен идемпотентный
  `backend/scripts/seed_e2e.py` (учитель + класс с кодом `E2E46`), который
  Playwright запускает только на изолированной БД `ai_teacher_e2e`.
