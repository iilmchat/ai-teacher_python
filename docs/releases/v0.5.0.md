# v0.5.0 — Learning Experience & Teaching Workflow

**Дата:** 2026-11-10 · **Тег:** `v0.5.0` · **Предыдущий:** `v0.3.3`
**Тип релиза:** single-node · **Обратная совместимость:** да (миграции и API
аддитивные)

v0.5.0 завершает этап «Learning Experience & Teaching Workflow»: ученик
проходит полный цикл «понял → написал → проверил → разобрал ошибку → починил»,
чат и песочница становятся рабочими инструментами, учитель разбирает работы,
администратор видит действия и качество, а уведомления собраны в одном центре.

## Главное

### Ученик

- **Проверка без траты попытки** — `POST /tasks/{id}/check` и кнопка «Пробная
  проверка»: тот же разбор по тест-кейсам, но счётчик попыток и статус не
  меняются. Лимит — 20 проверок в минуту.
- **История попыток** — каждая засчитанная отправка сохраняет код и разбор по
  кейсам; можно открыть детали и вернуть код в редактор. Retention — 90 дней.
- **Черновик не теряется** — автосохранение на сервере и на устройстве,
  восстановление после перезагрузки, очистка при отправке.
- **Поиск, фильтры и рекомендации** — фильтры каталога сохраняются в URL;
  «Рекомендуем дальше» объясняет, почему задача предложена.
- **Контекст задачи в чате** — `/chat?task=<id>`: ассистент видит условие, но
  не эталонное решение.

### Чат

- Заголовки, переименование и закрепление сессий.
- Остановка генерации, повтор ответа, оценка 👍/👎 с комментарием.
- Экспорт диалога в Markdown/JSON, шаблоны промптов по уровням.
- Передача кода «чат ↔ песочница» без потери черновика.

### Песочница

- Ввод `stdin`, лимиты и разбор кода на экране.
- История запусков с повторным запуском.
- Скачивание/загрузка `.py`, сниппеты, сохранение состояния редактора.

### Аккаунт

- Смена пароля с отзывом других сессий.
- Правка e-mail и имени, удаление аккаунта.
- Выгрузка своих данных в JSON (включая попытки, черновик и оценки ответов).
- Настройки уведомлений и языка; список активных сессий и «выйти везде».

### Учитель

- Просмотр кода и разбора работ ученика, комментарий к попытке.
- Drill-down по назначению: кто выполнил, кто в работе, кто просрочил, кто
  «застрял».
- Перенос и снятие срока, массовое добавление/снятие учеников, объявления
  класса с уведомлением.

### Администратор

- Журнал аудита `/admin/audit` с фильтрами и ссылками на сущности.
- Выгрузка аналитики (`users|tasks|attempts|activity`, CSV/JSON).
- Модерация задач из LLM-генерации и импорта: метрики застревания,
  публикация/снятие/возврат в доработку.
- Сводка качества LLM: негативные оценки, срезы по провайдеру/модели/уровню,
  проблемные темы; выгрузка для LLM_EVAL.
- Центр уведомлений `/notifications` с фильтром, «Прочитать все» и бейджем.

## Совместимость и обновление

- Все миграции `014`–`022` **аддитивные**; существующие данные не
  переписываются. `alembic check` — без расхождений.
- API только расширен: новые маршруты, необязательные поля запросов и
  дополнительные поля ответов. Удалений и смены типов нет; контрактный
  снапшот OpenAPI проходит проверку «только аддитивные изменения».
- Старые клиенты v0.3.3 продолжают работать; refresh-токены без `jti`
  принимаются один раз и получают строку сессии.
- Порядок обновления, новые переменные и два сценария отката —
  [docs/UPGRADE.md](../UPGRADE.md).

```bash
git checkout v0.5.0
bash scripts/backup.sh
cd backend && alembic upgrade head && alembic check && cd ..
docker compose -f docker-compose.prod.yml up -d --build
```

## Ограничения (D-001)

**v0.5.0 — single-node релиз.** В него **не входят**:

- multi-node и горизонтальное масштабирование, HA, DR и SLO 2.0;
- этап v0.4.0 «Production & Multi-node» — **отложен** решением владельца;
- registry/CD, автоматический TLS/домен, автоматические бэкапы и мониторинг
  как эксплуатационный контур.

**Продукт пока не готов к публичному production.** Он требует мер из
[docs/reports/DEVOPS_AUDIT_2026-11.md](../reports/DEVOPS_AUDIT_2026-11.md):
воспроизводимый артефакт и registry/CD с откатом, TLS/домен, автоматические
бэкапы, refresh-токен вне query string, trusted proxy и per-user лимиты,
наблюдаемость (scrape/алерты/Sentry) и детская безопасность (e-mail
verification/reset, guardrails LLM, согласия 152-ФЗ). Допустим только
закрытый пилот после выполнения этих мер.

Известные ограничения: `KI-018` (`.format()` в песочнице), `KI-023`
(merge-gate на GitHub Free), `KI-027` (access-токен не отзывается, токены в
localStorage; httpOnly-cookie/BFF — v0.6.0), `KI-031` (остаточные API-only
маршруты).

## Откат

Рекомендуется **откат только кода** на `v0.3.3`: схема аддитивна, старая
версия работает с ней, данные v0.5.0 сохраняются. Полный откат схемы
(`alembic downgrade 013`) удаляет историю попыток, черновики, заголовки
чатов, оценки, сессии, комментарии, объявления и данные модерации — только
после бэкапа. Подробно — [docs/UPGRADE.md](../UPGRADE.md) §0.5.
