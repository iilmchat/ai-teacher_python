# ASSISTANT_LEVELS — три уровня помощи

Уровень — это **образовательная политика**, а не только текст промпта.
Политика задаётся файлом промпта, а маршрут ответа — уровнем сессии.

---

## Сравнение

| | Базовый (`basic`) | Средний (`intermediate`) | Продвинутый (`advanced`) |
|---|---|---|---|
| Готовый код | ❌ запрещён | ❌ только фрагмент синтаксиса | ✅ полное решение |
| Наводящие вопросы | ✅ основа диалога | ⚠️ в конце | ⚠️ как усложнение |
| Объяснение причины ошибки | ✅ где, но не как исправить | ✅ причина + как правильно | ✅ причина + разбор |
| Примеры кода | только на **других** данных | правильный синтаксис (2–5 строк) | решение + альтернатива |
| Стиль и сложность | не обсуждаются | кратко | PEP 8, сложность, краевые случаи |
| Для кого | первые шаги | знает основы | уверенно решает, готовится к олимпиадам |
| Файл промпта | `prompts/basic.txt` | `prompts/intermediate.txt` | `prompts/advanced.txt` |

`gives_ready_code` отдаётся API (`/chat/levels`) и используется интерфейсом.

## Пример: одна и та же ошибка

Код ученика:

```python
code = input()
if code = "hello":
    print("Hi!")
```

### Базовый

> В строке с `if` используется не тот оператор. В Python есть два похожих
> символа: один «кладёт» значение в переменную, другой «сравнивает».
> Какой из них нужен, чтобы проверить условие?
>
> Попробуй вспомнить: что делает `=` в строке `code = input()`?

### Средний

> Причина — оператор присваивания в условии. Для сравнения нужен `==`:
>
> ```python
> if code == "hello":
>     print("Hi!")
> ```
>
> - `=` — присваивание (`x = 5`);
> - `==` — сравнение (`if x == 5`);
> - Python не разрешает присваивание внутри `if`.
>
> Мини-упражнение: сравни две переменные `a` и `b` и выведи `да`, если равны.

### Продвинутый

> Ошибка в операторе сравнения — в условии использован `=`.
>
> ```python
> code = input()          # получаем строку
> if code == "hello":     # сравниваем, а не присваиваем
>     print("Hi!")
> ```
>
> Почему так: `=` меняет значение переменной и возвращает его, `==` только
> сравнивает. В `if` ожидается выражение-условие.
>
> Альтернатива через `match` (Python 3.10+):
>
> ```python
> match code:
>     case "hello":
>         print("Hi!")
>     case _:
>         print("...")
> ```
>
> Усложнение: сделайте сравнение нечувствительным к регистру
> (`code.strip().lower()`) и обработайте пустой ввод.

## Как выбирается уровень

1. У пользователя есть уровень по умолчанию (`users.level`).
2. При создании чата уровень можно переопределить (`POST /chat/sessions {level}`).
3. Сессия хранит свой уровень — параллельные диалоги могут иметь разные уровни.
4. Если файла промпта нет, `resolve_level` откатывает на `basic`, чат работает.

```
Пользователь (level=intermediate)
   └─ Чат A (level=intermediate)  → prompts/intermediate.txt
   └─ Чат B (level=advanced)      → prompts/advanced.txt
```

## Требования к промптам

- Живут в файлах `backend/app/services/llm/prompts/<level>.txt` (не в коде).
- Изменение промпта — отдельный PR + прогон тестов `test_prompts.py`.
- Тесты проверяют маркеры политики:
  - `basic`: «не давай готовый код», «наводящие вопросы»;
  - `intermediate`: правильный синтаксис, «не выдавать полное решение»;
  - `advanced`: «полное решение», альтернативы.
- Оценка качества на живой модели — [LLM_EVAL.md](LLM_EVAL.md) (пока не
  проведена, KI-008).
