# ASVS L1 — самооценка (S38-001)

> OWASP Application Security Verification Standard, Level 1 (базовый).
> Это **самооценка с доказательствами**, не сертификация. Дата: 2026-11-12,
> версия v0.6.0. Связанные: `SECURITY_AUDIT.md`, `DPIA.md`, `SECURITY.md`.
>
> Легенда: ✅ выполнено и покрыто тестом/конфигом · ⚠️ частично/принятый риск ·
> ❌ не применимо к этому продукту.

| Пункт | Статус | Доказательство |
|-------|--------|----------------|
